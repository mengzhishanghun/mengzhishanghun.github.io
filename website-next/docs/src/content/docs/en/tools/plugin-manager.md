Find and manage UE plugins。

## Features

- Scan project, engine, and marketplace plugins
- Search and inspect dependencies and conflicts
- Enable, move, or send plugins to the recycle bin

## Quick start

1. Download the Windows executable from Releases.
2. Place it in your Unreal Engine project directory, run it, and scan plugins.
3. Review dependencies, conflicts, and target folders before applying changes.
