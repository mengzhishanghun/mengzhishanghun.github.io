Embed and copy local Markdown images。

## Features

- Convert local images to Base64
- Support wiki-style image references
- Set prefix/suffix options and use the GUI or CLI

## Quick start

1. Get the release, or follow the README and environment.yml to set up the source environment.
2. Choose a Markdown file and check image references and conversion options.
3. Convert and copy the result, then verify text and image rendering on your publishing platform.
