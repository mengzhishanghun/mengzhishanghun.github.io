统一查找与管理 UE 插件。

## 主要功能

- 扫描项目、引擎与商城插件
- 搜索并分析依赖和冲突
- 执行启停、移动与回收站删除

## 快速开始

1. 从 Release 下载 Windows 程序。
2. 放入 Unreal Engine 项目目录并运行，开始扫描插件。
3. 先核对依赖、冲突和目标目录，再执行需要的操作。
