Markdown 本地图片内嵌与复制。

## 主要功能

- 本地图片转换为 Base64
- 支持 Wiki 风格图片引用
- 配置前后缀，通过 GUI 或 CLI 使用

## 快速开始

1. 获取 Release 程序，或按 README 使用 environment.yml 配置源码环境。
2. 选择 Markdown 文件，核对图片引用和转换选项。
3. 转换并复制结果，在发布平台检查图片和文本显示。
