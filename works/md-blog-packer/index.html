Markdown 图片发布工具

将 Markdown 中的本地图片转成 Base64 内嵌格式，便于导出和复制到支持的平台。

解决什么问题

本地 Markdown 的图片引用不会把图片文件一起带到其他平台。MDBlogPacker 在导出时把本地图片转换为 Base64 内嵌文本，适用于允许这种格式的目标平台。

主要功能

  • 识别普通 Markdown 图片语法与 Obsidian Wiki 图片引用。
  • 批量转换本地图片，保留网络图片和已内嵌图片。
  • 提供图形界面与 CLI，结果可复制或导出为文件。
  • 支持在导出文本前后追加版权声明等内容。

使用边界

目标平台需要接受 Base64 图片。内嵌会增大文件体积，因此日常编辑仍保留独立图片，只在需要跨平台发布时导出。自己的网站更适合将图片作为独立资源同步。
