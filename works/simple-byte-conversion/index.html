作品简介

SimpleByteConversion 为 UE 蓝图提供常用数据到字节数组、结构体到字节数组，以及结构体与 JSON 字符串的双向转换接口。它让需要网络传输、文件存储或外部程序交换数据的蓝图逻辑，能够先取得明确的字节或文本表示，再交给相应的通信与存储环节。

背景与目标

蓝图中处理整数、浮点数或自定义结构体时，直接得到可发送的字节数组并不方便。不同来源的数据还可能采用二进制或 JSON 表示。作品把这些基础转换整理成可调用节点，减少每个项目为同类数据重新编写接口的工作，同时让转换结果与后续传输、持久化操作分开。

核心能力

基础类型与字节数组

提供 int32、int64、float、double、bool 和 FString 的 ToBytes / FromBytes 成对接口。基础数值按其内存表示写入字节数组，字符串使用 UTF-8。节点可作为蓝图纯函数使用，适合在发送前编码，或在收到同格式数据后还原。

结构体二进制转换

StructToBytes 与 BytesToStruct 面向自定义结构体。蓝图接口通过泛型结构体参数接收不同类型，再输出字节数组或还原结构体。结构体类型与字段布局是转换双方共同的契约，接收端不能只凭字节长度猜测含义。

结构体 JSON 转换

StructToJsonString 与 JsonStringToStruct 在结构体和可读文本之间转换。JSON 更适合与 Python 等外部程序交换或查看字段；作品也处理字段名和浮点数输出中的转换问题，使文本结果更便于识别与核查。

适用场景

可用于 UE 项目在 UDP/TCP 通信前整理待发送数据，或在文件存储前把结构化状态转换为字节。与外部程序交互时，可选 JSON 来核对字段；这些示例中的网络连接和文件读写应由其他模块完成。

适用范围与边界

转换接口本身不定义跨语言协议。发送端与接收端仍需约定类型、字段、编码和版本，并用固定样例验证往返结果。结构体变更后应重新检查旧数据的兼容性，不能把能成功调用转换节点等同于数据已正确解释。
