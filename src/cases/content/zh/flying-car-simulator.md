## 项目介绍

这是一个基于 UE 与 AirSim 的 VR 飞行仿真项目。用户佩戴头显观察飞行场景，通过飞行手柄控制飞行器前后移动、左右侧移、升降和转向。项目还接入六轴运动平台，将飞行器的运动数据转换为平台侧的控制输入。

我负责飞行手柄接入与操作映射、AirSim 控制适配、VR 相机接入，以及六轴平台的数据处理与通信。

| 项目部分 | 主要内容 |
| --- | --- |
| 体验方式 | VR 头显观察、飞行手柄操作 |
| 飞行控制 | AirSim 接入、分轴输入、速度与朝向控制 |
| 运动联动 | 飞行状态读取、洗出处理、六轴数据发送 |
| 版本适配 | UE 5.6 接口与初始化调整 |
| 个人职责 | 输入设备接入、飞控适配、参数配置、相机接入与平台通信 |

## 功能实现与技术难点

### VR 视角与相机接入

项目通过 OpenXR 接入 VR，配置飞行器上的相机，让用户在头显中观察飞行场景。手柄负责控制飞行器运动，相机系统负责观察视角，两部分分别接入。

我负责 VR 与相机配置调整，并处理项目相机和 AirSim 自带相机管理之间的关系。AirSim 原有的 CameraDirector 初始化被停用，观察视角交由项目侧管理，避免两套逻辑同时干预相机。

### 飞行手柄与输入映射

通过 SimpleController 获取设备输入，在此基础上接入自定义控制模块。模块读取设备配置表，将设备轴、按钮和方向帽绑定到项目中的操作事件，再由蓝图把事件转交给飞行控制器。

飞行操作分为前后移动、左右侧移、左右转向和上升下降四组。设备轴可以配置偏移和缩放，用于调整输入范围与正反方向；不同设备通过配置表对应各自的输入绑定，飞行控制器统一接收这四组操作值。

控制模块还处理设备接入、断开和控制启停。键盘操作也接入同一套飞行控制接口，便于在不使用飞行手柄时调试场景与控制逻辑。

### 飞控接入与参数配置

基于 AirSim 的多旋翼接口接入飞行控制，在初始化时启用 API 控制、解锁电机并应用控制参数。设备输入先按轴限制幅度，再换算成水平速度、垂直速度和目标偏航角，由 Pawn 每帧提交指令。

前后和左右操作采用机体坐标，水平方向根据飞行器当前的偏航角转换，因此“向前”会跟随机头朝向。升降单独处理，转向则维护独立的目标角度。

最大水平速度、垂直速度和偏航速率开放为可编辑参数，角度、角速度与速度控制的比例增益也可以分别调整，方便在 UE 中配置操作响应。

### 六轴平台的数据联动

我负责读取飞行器的运动状态，接入洗出处理，并通过 UDP 向六轴平台侧发送数据。平台联动使用仿真运行中的速度和姿态数据，与手柄输入的目标值分开处理。

我重写了飞行器的速度查询，从 AirSim 获取仿真速度，并转换成 UE 使用的单位和方向。联动蓝图根据前后两次采样的速度、姿态及时间间隔，计算加速度等运动量，交给洗出模块处理。

洗出模块提供平移、旋转和倾斜通道的比例调整，以及滤波和角速度限制参数。我将这些接口接入联动蓝图，再把输出转换为字节报文，通过独立的六轴发送通道交给平台侧。

### 独立的偏航控制

#### 负责的实现

分别维护移动方向与机头朝向。初始化目标偏航角时，使用飞行器当前的偏航估计值；之后根据转向输入和 DeltaTime 累加角度，并处理角度环绕。

飞行器可以侧向或斜向移动，同时单独控制转向，不必让机头始终朝向移动方向。

#### 难点与处理

平移与机头朝向共用方向判断逻辑时，同时输入前后与左右操作，可能引起大幅偏航。我将目标偏航角单独维护，水平方向的输入转换则只使用当前 yaw。

速度指令决定如何移动，目标偏航角决定机头朝向。初始化时使用实际偏航值，也避免了程序刚启动就让机头转向默认角度。

### UE 与 AirSim 的接口适配

#### 负责的实现

统一处理厘米与米的换算，以及 UE 与 NED 上下方向的转换。AirSim 的 NED 坐标系中 Z 轴向下，UE 的 Z 轴向上，因此升降指令和返回的速度数据都需要处理方向差异。

同时调整 UE 5.6 下的接口与初始化逻辑，将控制调用改为非阻塞方式。每帧提交当前目标后，游戏线程继续执行场景、相机和界面逻辑。

#### 难点与处理

旧控制流程使用带持续时间的接口，等待控制动作结束会影响游戏线程更新。仿真程序需要持续读取操作，这种等待也会影响输入、画面和相机的处理。

我改用非阻塞的 `setVelocityCommandBodyFrame`，由 Pawn 每帧提交当前速度与朝向目标。接口返回后，游戏线程继续执行其他逻辑，后续帧再更新控制目标。

项目相机与 AirSim 自带相机管理逻辑同时初始化时，视角变化容易被误认为飞行器运动异常。我调整 CameraDirector 的初始化逻辑，将飞行控制与观察视角分别处理，完成项目相机的接入。
