## 作品简介

MCPDevTools 是开发中的 UE 编辑器 MCP 插件，围绕资产工具与只读开发诊断提供工具接口。当前功能与兼容性仍在验证。

## 开发方向

围绕资产工具与只读开发诊断，让外部 AI 工具通过 MCP 接入 UE 编辑器中的相关工作流程。具体操作范围和反馈能力随开发迭代调整。

## 开发状态

项目处于开发阶段，使用说明见[MCPDevTools 教程](/zh/docs/guides/ue-tools/mcp-dev-tools-guide/)。UE 5.2–5.8 相关版本仍在开发，兼容性待确认，不能视为已经完成各版本测试。
