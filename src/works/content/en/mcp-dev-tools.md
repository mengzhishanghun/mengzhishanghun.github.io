## About this work

MCPDevTools is an Unreal Editor MCP plugin in development, providing tool interfaces for asset tools and read-only development diagnostics. Features and compatibility are still being verified.

## Development direction

The project focuses on asset tools and read-only development diagnostics, connecting external AI tools to related Unreal Editor workflows through MCP. The scope of operations and feedback capabilities may change as development continues.

## Development status

The project is in development. See the [MCPDevTools user guide](/docs/guides/ue-tools/mcp-dev-tools-guide/) for usage instructions. Work on UE 5.2–5.8 versions is ongoing; compatibility is to be confirmed and does not imply that all versions have been tested.
