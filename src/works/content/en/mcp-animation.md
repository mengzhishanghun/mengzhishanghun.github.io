## About this work

MCPAnimation is an Unreal Editor MCP plugin in development, providing tool interfaces for Animation Blueprints, state machines and animation assets. Features and compatibility are still being verified.

## Development direction

The project focuses on Animation Blueprints, state machines and animation assets, connecting external AI tools to related Unreal Editor workflows through MCP. The scope of operations and feedback capabilities may change as development continues.

## Development status

The project is in development. See the [MCPAnimation user guide](/docs/guides/ue-tools/mcp-animation-guide/) for usage instructions. Work on UE 5.2–5.8 versions is ongoing; compatibility is to be confirmed and does not imply that all versions have been tested.
