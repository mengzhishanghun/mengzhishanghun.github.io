## About this work

MCPUMG is an Unreal Editor MCP plugin in development, providing tool interfaces for Widget trees, properties and animations. Features and compatibility are still being verified.

## Development direction

The project focuses on Widget trees, properties and animations, connecting external AI tools to related Unreal Editor workflows through MCP. The scope of operations and feedback capabilities may change as development continues.

## Development status

The project is in development and has no public usage documentation yet. Work on UE 5.2–5.8 versions is ongoing; compatibility is to be confirmed and does not imply that all versions have been tested.
