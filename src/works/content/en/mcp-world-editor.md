## About this work

MCPWorldEditor is an Unreal Editor MCP plugin in development, providing tool interfaces for Actors, levels, terrain and viewports. Features and compatibility are still being verified.

## Development direction

The project focuses on Actors, levels, terrain and viewports, connecting external AI tools to related Unreal Editor workflows through MCP. The scope of operations and feedback capabilities may change as development continues.

## Development status

The project is in development and has no public usage documentation yet. Work on UE 5.2–5.8 versions is ongoing; compatibility is to be confirmed and does not imply that all versions have been tested.
