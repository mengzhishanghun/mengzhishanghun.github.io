## Start and Detect the Engine

1. Download `UEPluginManager.exe` from Release, place it next to the target project’s `.uproject` file, and run it.
2. The tool detects installed engines through the registry and source builds by their GUID. Once it finds the associated engine, open the Project, Marketplace, or Engine tab to see the plugins it found.
