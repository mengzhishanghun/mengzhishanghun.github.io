## v1.0.0

Packages a plugin for multiple Unreal Engine paths. The GUI shows each engine’s status as packaging runs and lets you switch between their logs. If packaging fails, it saves the log automatically. Fab post-processing can remove intermediate files and copy materials such as README, LICENSE, and Docs.

Published on [GitHub Release](https://github.com/MZSH-Tools/UEPluginAutoPacker/releases/tag/v1.0.0).
