## Check Dependencies on Submission

`Enable Auto Add Dependencies` is on by default. When submitting a changelist, the plugin checks dependencies of the assets being submitted. Tracked files need no action. Select the untracked dependencies you want to add, then confirm. Teams can leave this on to avoid missing dependencies in other members’ builds.

## Check Selected Assets from the Context Menu

Before submitting, check that the dependencies you confirmed now appear in the pending submission. Unchecked files are left out of this selection. If you need one later, run the dependency check again on the original asset or folder.

Select one or more assets or folders in the Content Browser and choose **Add Untracked Dependencies** from the **Simple Asset Cleaner** context submenu. Review the untracked dependencies found in the selection and confirm the files to add.
