## Find classes and edit notifies

| Tool | Purpose |
|---|---|
| `ListNotifyClasses` | Discover native and Blueprint AnimNotify/AnimNotifyState classes. |

| Tool | Purpose |
|---|---|
| `AddNotify` / `RemoveNotify` | Add or remove a notify on an AnimSequence or Montage. |
