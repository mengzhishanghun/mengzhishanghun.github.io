## v1.0.0

The first release compiles and launches Unreal Engine projects from a GUI. With the EXE next to the `.uproject`, the tool identifies the project and engine version and shows the compile log as it runs. The tool launches the project after a successful build.

Published on [GitHub Release](https://github.com/MZSH-Tools/UEQuickStart/releases/tag/v1.0.0).
