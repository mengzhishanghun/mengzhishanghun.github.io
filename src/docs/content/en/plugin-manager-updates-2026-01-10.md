## v1.0.0

The first release scans project, Marketplace, and engine plugins. When enabling or disabling a plugin, you can confirm whether to apply the related dependency changes. The tool can move or delete plugins, correct their directories, sort them, analyze dependencies, and detect name conflicts. Search ignores case and accepts multiple space-separated terms.

Published on [GitHub Release](https://github.com/MZSH-Tools/UEPluginManager/releases/tag/v1.0.0).
