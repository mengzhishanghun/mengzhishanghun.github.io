## v1.0.0

This is the first stable release. The tool scans a changelist, reads the actual casing of local paths, and can correct each part of a path. File status is shown in gray, green, or red. Double-click to edit and preview the result as you work. If the consistency check fails, the tool tries a two-step `move`. The single EXE requires no separate Python installation.

Published on [GitHub Release](https://github.com/MZSH-Tools/P4CaseSync/releases/tag/v1.0.0).
