## Install the Plugin and Open Settings

Copy the plugin folder to the project’s `Plugins` directory, restart the editor, and open `Edit > Project Settings > Simple Asset Namer`. Review the default type affixes and path scope. English is the default; switching to Chinese updates the UI, prompts, and logs immediately.

## Try the Naming Rules

Check that automatic renaming on creation is enabled and that the test folder is within the rule’s scope. If you use the default Blueprint rule, compare the new name with its expected prefix.

Create a test Blueprint. For example, check whether `MyCharacter` becomes `BP_MyCharacter`. For existing assets, start with a small folder.
