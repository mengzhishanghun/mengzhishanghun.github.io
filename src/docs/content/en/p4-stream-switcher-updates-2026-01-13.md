## v1.1.0

- When you mark a directory for offline work, the tool preserves local edits with `reconcile` and puts the differences in the default changelist.
- You can open P4V from the tool with the current client already selected.
- The tool clears the read-only attribute before deleting a file, fixing deletions that failed during Perforce sync.
