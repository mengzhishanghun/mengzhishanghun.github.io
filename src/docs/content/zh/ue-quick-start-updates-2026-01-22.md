## v1.0.0

首个版本通过 GUI 编译并启动 Unreal Engine 项目。将 EXE 放在 `.uproject` 同级目录，工具会自动识别项目和引擎版本、实时显示编译日志。编译成功后会启动项目。

此版本已在 [GitHub Release](https://github.com/MZSH-Tools/UEQuickStart/releases/tag/v1.0.0) 发布。
