## 支持的序列和输出

**Smooth** 可处理一个或多个 LevelSequence，支持 ControlRig 参数段的 Transform 和 Scalar 通道。工具自动读取序列帧率；批量创建新序列时会统一使用后缀命名。输出可覆盖原序列，也可生成新序列。

## 从内容浏览器应用平滑

1. 在内容浏览器中右键选择一个或多个 LevelSequence 资产
2. 从右键菜单中选择 **Smooth**
3. 选择平滑算法并调整参数
4. 选择输出方式（覆盖原序列或创建新序列）
5. 点击 **确定** 应用
