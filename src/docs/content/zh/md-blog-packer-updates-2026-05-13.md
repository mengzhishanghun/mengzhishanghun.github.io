## v1.0.1

GUI 的文件浏览器默认打开 EXE 所在目录，启动时自动选中该目录中的第一个 `.md` 文件。每次启动都会重新查找 Markdown 文件，文件路径不再缓存。README 补充了 GUI 使用说明。

此版本已在 [GitHub Release](https://github.com/MZSH-Tools/MDBlogPacker/releases/tag/v1.0.1) 发布。
