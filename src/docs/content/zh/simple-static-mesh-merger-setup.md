## 打开 Static Mesh Merger

1. 打开 Unreal Engine 编辑器
2. 点击顶部菜单 `Window > Static Mesh Merger`
3. 工具窗口将作为可停靠面板打开

## 识别工具栏按钮

**Break Level Instances** 用于拆分场景中的 LevelInstance；**Refresh** 手动刷新预览；类型下拉框在 HISM 和 ISM 之间切换，默认为 HISM；**Merge Selected** 合并当前选中的分组。
