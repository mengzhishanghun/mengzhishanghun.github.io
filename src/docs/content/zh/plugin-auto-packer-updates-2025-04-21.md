## v1.0.0

支持为多个 Unreal Engine 路径打包插件。界面实时显示各引擎的打包状态，可以切换查看对应的日志。打包失败时，工具会自动保存日志。Fab 整理可清理中间文件，并复制 README、LICENSE 和 Docs 等内容。

此版本已在 [GitHub Release](https://github.com/MZSH-Tools/UEPluginAutoPacker/releases/tag/v1.0.0) 发布。
