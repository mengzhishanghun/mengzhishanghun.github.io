# 如何实现cmd可以访问conda但不能通过默认环境访问python

# 这么做的好处

通常情况下，安装miniconda后，系统会将base作为默认环境，直接用它执行python，导致base环境很容易被污染。

我现在需要cmd能正常访问conda命令，但不能访问python。

# 第一步

确保机器主环境没有安装python，下载并安装miniconda，安装时勾选just me，且不设置环境变量

# 第二步

打开cmd窗口，使用绝对路径执行conda init操作。

```
C:\Users\mengzhishanghun\miniconda3\Scripts\conda.exe init cmd.exe

```

重新打开cmd窗口后，就可以正确识别conda指令。

# 第三步

现在输入

```
conda config --set auto_activate_base false
```

这样就会禁止默认进入base环境。此时输入where python，返回为

```
C:\Users\mengzhishanghun>where python
信息: 用提供的模式无法找到文件。
```
