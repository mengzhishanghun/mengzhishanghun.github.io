# 自定义配置DeveloperSettings

# 创建
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A1)
创建一个继承自UDeveloperSettings的类
类属性中Config=Game意思是在Game.ini中配置，加上DefaultConfig，就是DefaultGame.ini
config=后面跟的就是配置文件名
所以这里是在DefaultVehicle.ini中配置



# ini配置格式
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A2)
配置格式为[/script/模块名/类名]
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A3)
Map格式是((key,value),(key,value))
Map和Array都可以通过+在下面续写，不用都写在一行

# 编辑器项目配置
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A4)
DisplayName=后面跟的是在编辑器项目配置中的名字

根据config=后跟的值来分类
可以是game engine plugins
也可以自定义，自定义默认在engine类

在你加了DefaultConfig后改变这里的值就会自动生成配置文件

# 调用
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A5)
c++中通过GetDefault来获得
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A6)
蓝图中可以通过调用GetClassDefaults来获得
# 打包排除
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A7)
首先要在DefaultGame.ini中添加要排除的配置文件
![](/media-occurrence/blog%3Acnblogs-19165500%3Amedia%3A8)
然后在对应模块中添加引用声明，这样打包的时候就会自动把文件拷贝到打包后的config中
这样做的好处是打包后也可以通过编辑配置文件来更改游戏规则
