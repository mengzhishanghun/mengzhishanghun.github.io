# 无法删除Stream Depot怎么处理

# 先查看当前的流有哪些

使用指令

```
p4 streams -a
```

![](/media-occurrence/blog%3Acnblogs-19143260%3Amedia%3A1)

test和Unreal Depot都是我要删除的Depot。test是完整的，另一个先用stream -f -d 删除后被标记为deleted，但depot仍然无法删除。

# 强制删除

使用以下指令强制删除：

```
p4 stream -d --obliterate -y -f //test/UEPublic/test1
```

![](/media-occurrence/blog%3Acnblogs-19143260%3Amedia%3A2)

完成后，返回p4admin删除Depot即可。

# 提示has active clients; cannot delete until they are removed.

这表示还有一个工作区正在使用这个流，找到后删除该工作区，或将它切换到其他流即可。
