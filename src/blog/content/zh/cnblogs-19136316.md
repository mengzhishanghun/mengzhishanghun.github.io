# 前言

这是最近做MetaHuman项目发现的问题，当头部和身体同时播放不同动画的时候，脖子附近会出现穿模现象，这个问题在LevelSequence中暂时没有发现。

# 解决方案

![](/media-occurrence/blog%3Acnblogs-19136316%3Amedia%3A1)

如图，你只需要找到那个头部动作，在详情页面中将AdditiveSettings设置成这样就可以了。

该办法来自youtube，链接是[Combine Face and Body Animations - Metahumans in Unreal Engine 5.2](https://www.youtube.com/watch?v=ddQKMTKGpTE)

虽然视频时5.2版本但是5.6版本亲测可用。
