# 解决UObject蓝图缺少上下文的问题

# 问题简述

通常情况下，新建一个继承自UObejct的蓝图后，你会发现它不仅无法获取PlayerController

![](/media-occurrence/blog%3Acnblogs-19165488%3Amedia%3A1)

也无法创建UI，否则会报错

![](/media-occurrence/blog%3Acnblogs-19165488%3Amedia%3A2)

原因是父类没有重写GetWorld函数，蓝图编译时拿不到上下文，因此报错。

# 解决方案

解决办法是在父类中重写GetWorld函数，但有几点需要注意。

在.h中添加
```C++
virtual UWorld* GetWorld() const override;
```

在.cpp中添加

```C++
UWorld* UAIFlow::GetWorld() const  
{  
    if (IsTemplate() || !GetOuter())  
    {  
       return nullptr;  
    }  
  
    return GetOuter()->GetWorld();  
}
```

注意，这里不能直接return，必须按上面的方式处理才能解决问题。

我是在Actor中创建这个对象的，GetOuter直接指向那个Actor，因此能正确拿到GetWorld。return部分需要根据自己的情况编写。
