UE: Quickly Creating a Map
===

This only covers quickly creating a usable standard map, excluding World Partition maps.

First, press Ctrl+Space to open the Content Browser, then right-click and choose Level

![](/media-occurrence/blog%3Acnblogs-19184043%3Amedia%3A1)

Open Window -> Environment Light Mixer

![](/media-occurrence/blog%3Acnblogs-19184043%3Amedia%3A2)

![](/media-occurrence/blog%3Acnblogs-19184043%3Amedia%3A3)

Click these buttons in sequence to create a complete standard map, quickly and conveniently.

If you want to create terrain, switch to Landscape mode

![](/media-occurrence/blog%3Acnblogs-19184043%3Amedia%3A4)

![](/media-occurrence/blog%3Acnblogs-19184043%3Amedia%3A5)

You can adjust the relevant values or simply create it with the defaults

After creation, return to Selection mode

The final scene
