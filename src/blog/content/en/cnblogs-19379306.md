UE: How to See Exactly Which Files Were Packaged
===

# Result

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A1)

These are the files after packaging. Unlike the usual packaged files, this lets you see all the configuration files, assets, plugins, and so on included in the completed package.

# How to Configure It

Using UE5.2 as an example, first open Packaging Settings.

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A2)

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A3)

Uncheck Use Pak File and Use Io Store. Both are usually checked by default.

You can then see the project files after packaging.
