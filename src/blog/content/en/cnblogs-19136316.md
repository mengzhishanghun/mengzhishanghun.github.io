# A One-Click Fix for MetaHuman Head Clipping During Animation

# Introduction

In a recent MetaHuman project, playing different head and body animations simultaneously caused clipping around the neck. I have not observed this issue in LevelSequence so far.

# Solution

![](/media-occurrence/blog%3Acnblogs-19136316%3Amedia%3A1)

As shown, find the head animation and set AdditiveSettings in its Details panel to match these settings.

This method comes from YouTube: [Combine Face and Body Animations - Metahumans in Unreal Engine 5.2](https://www.youtube.com/watch?v=ddQKMTKGpTE).

Although the video uses version 5.2, I personally tested it successfully in 5.6.
