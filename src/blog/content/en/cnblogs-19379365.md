UE: Changing the Cache Path
===

The easiest way is to search for \Engine\Config\BaseEngine.ini using Evenyting.

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A1)

Find the file for the engine you want to modify and change %ENGINEVERSIONAGNOSTICUSERDIR%DerivedDataCahe to %GAMEDIR%DerivedDataCache. GAMEDIR refers to the project path.

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A2)

Finally, find the previous default path on the C drive and delete the cache. What? You do not know where it is?

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A3)
