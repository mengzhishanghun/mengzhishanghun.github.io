# Changing the Cache Path

The simplest method is to search for \Engine\Config\BaseEngine.ini with Evenyting.

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A1)

Find the file for the engine you want to modify, then change %ENGINEVERSIONAGNOSTICUSERDIR%DerivedDataCahe to %GAMEDIR%DerivedDataCache. GAMEDIR refers to the project path.  

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A2)

Finally, find the previous default path on drive C and delete the cache. What? You do not know where it is?  

![](/media-occurrence/blog%3Acnblogs-19379365%3Amedia%3A3)

Everything is the GOAT!
