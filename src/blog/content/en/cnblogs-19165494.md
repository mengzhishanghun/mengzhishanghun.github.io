# PixelStreaming

# What Is Pixel Streaming?

[UE5.4 Pixel Streaming](https://dev.epicgames.com/documentation/en-us/unreal-engine/getting-started-with-pixel-streaming-in-unreal-engine?application_version=5.4)

# How to Use It

## Enable the Plugin
![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A1)
Enable the PixelStreaming plugin.
## Add Launch Parameters

>-AudioMixer -PixelStreamingIP=127.0.0.1 -PixelStreamingPort=8888 -PixelStreamingEncoderCodec=VP9

### Through Editor Settings

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A2)

Editor Preferences → Play → Additional Launch Parameters

Notes:

1. The official instructions use -PixelStreamingIP=localhost, but localhost did not work in my testing. Use 127.0.0.1 here.
2. This only takes effect in standalone mode. You can change the default standalone window size in the settings above.
3. Version 5.3 supports only AV1, H264, VP8, and VP9 video streaming codecs; 5.4 supports H265. I recommend VP9 for broader compatibility and efficient encoding. It handles three 4K screens without issues.

### Launching Through a Shortcut

This is familiar territory, so I will skip the details.

## Start the Signalling Server

### Download from GitHub

[EpicGamesExt/PixelStreamingInfrastructure: The official Pixel Streaming servers and frontend. (github.com)](https://github.com/EpicGamesExt/PixelStreamingInfrastructure/)

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A3)
Go directly to the Releases page.

Download the release matching your engine version. Why use a release? It is already built and ready to use. Downloading the mainline or a branch instead may report a missing player.html file.

### Download and Install Node

[Node.js — Download Node.js® (nodejs.org)](https://nodejs.org/en/download/prebuilt-installer/current)

Download it and install with all defaults.

### Start the Signalling Server

Open SignallingWebServer in the files you downloaded from GitHub.

Open CMD at this path.

Run:
> node cirrus.js

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A4)

It looks like this after a successful start:

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A5)

# Accessing It in a Browser

Enter 127.0.0.1 directly in the browser; on another computer, enter the IP address.

The default listening port is 80, so it can be omitted. For another port, specify it explicitly.
