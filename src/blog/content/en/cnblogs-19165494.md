# What Is Pixel Streaming?

[UE5.4 Pixel Streaming](https://dev.epicgames.com/documentation/en-us/unreal-engine/getting-started-with-pixel-streaming-in-unreal-engine?application_version=5.4)

# How to Use It

## Enable the Plugin

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A1)\
&#x20;Just enable the PixelStreaming plugin

## Add Launch Arguments

> -AudioMixer -PixelStreamingIP=127.0.0.1 -PixelStreamingPort=8888 -PixelStreamingEncoderCodec=VP9

### Through Editor Settings

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A2)

Editor Preferences -> Play -> Additional Launch Parameters

Notes:

1. The official documentation uses -PixelStreamingIP=localhost, but in my testing localhost did not work, so enter 127.0.0.1 directly here
2. This only takes effect in standalone mode. You can change the default standalone window size through the window settings above
3. Video encoding for streaming in 5.3 only supports AV1, H264, VP8, and VP9; 5.4 supports H265. I recommend VP9 here for its broader compatibility. Even three 4K screens work fine, and its encoding efficiency is high too

### Launch Through a Shortcut

This is familiar territory, so I will not go into it again.

## Start the Signaling Server

### Download from GitHub

[EpicGamesExt/PixelStreamingInfrastructure: The official Pixel Streaming servers and frontend. (github.com)](https://github.com/EpicGamesExt/PixelStreamingInfrastructure/)

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A3)\
&#x20;Go straight to the releases page

Find and download the version matching your engine. Why download a release directly? Because it is already built and ready to use. Downloading the main branch or another branch directly will produce a missing player.html error.

### Download and Install Node

[Node.js — Download Node.js® (nodejs.org)](https://nodejs.org/en/download/prebuilt-installer/current)

After downloading, install it with all the default settings.

### Start the Signaling Server

Open the files you downloaded from GitHub -> SignallingWebServer

Open cmd in this directory

Run the command:

> node cirrus.js

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A4)

This is what success looks like:

![](/media-occurrence/blog%3Acnblogs-19165494%3Amedia%3A5)

# Access It in a Browser

Simply enter 127.0.0.1 in the browser; on another computer, enter the IP address.

The default listening port here is 80, so you can omit it. For another port, you need to change it explicitly.
