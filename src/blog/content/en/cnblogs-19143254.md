Perforce: Fixing Garbled Chinese Text
===

Chinese text becomes garbled because Unicode mode is not enabled on the server.

Normally, when a client first connects to a Unicode-enabled server, it displays an option. Just select utf8; there is no need to modify p4 set manually.

### Fixing a Windows Server

Run `p4d -xi` in the server root directory, then restart.

Note: the official recommendation is to run this command on an empty server. If files are present, back them up before converting. See the official documentation for details.

### Fixing a Server Using a Docker Image

For a Docker installation image, I recommend hawkmoth, which uses unicode mode by default. The top-ranked ambakshi image does not use unicode mode by default.
