# Fixing Garbled Chinese Text

Garbled Chinese text occurs because Unicode mode is not enabled on the server.

Normally, the client displays a choice when first connecting to a Unicode-enabled server. Select utf8; there is no need to edit p4 set manually.

### Fixing a Windows Server

Run `p4d -xi` in the server root directory, then restart.

Note: the official recommendation is to run this command on an empty server. If files already exist, back them up before converting. See the official documentation for details.

### Fixing a Server Installed from a Docker Image

For a Docker installation, I recommend the hawkmoth image, which uses Unicode mode by default. The top-ranked ambakshi image does not use Unicode mode by default.
