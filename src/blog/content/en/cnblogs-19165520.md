# Traversing Actor Properties for Sequence Recording

```C++
void AMyDrivingReplayActor::AddInterp(const UStruct* ObjectClass)
{
	for (TFieldIterator<FProperty> It(ObjectClass); It; ++It)
	{
		It->SetPropertyFlags(CPF_Interp);
			
		if (const FStructProperty* AsStructProperty =  CastField<FStructProperty>(*It))
		{
			AddInterp(AsStructProperty->Struct);
		}
	}	
}
```

This recursively sets the structs that need recording within this Actor to CPF_Interp, which indicates that their values can be recorded by LevelSequence. The function traverses all properties inside the structs and also sets them to CPF_Interp.

![](/media-occurrence/blog%3Acnblogs-19165520%3Amedia%3A1)

Because it is called only in BeginPlay, it does not affect properties in their normal state; these properties change only when the game starts.
