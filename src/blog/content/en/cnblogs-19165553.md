# Setting Up a Listen Server

The simplest way to start a listen server is to create a desktop shortcut and set its target to UnrealEditor.exe MyProject.uproject ?listen -game.

To join, replace the ?listen launch parameter with the IP address. Note that there is no leading -.

You can also connect directly to a listen server from within the editor.

The server command is open LevelName?listen.

The client command is open ServerIP.
