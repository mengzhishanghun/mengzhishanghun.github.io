UE: How to Set Up a Listen Server
===

> © [mengzhishanghun](https://github.com/mengzhishanghun) · Original article\
> &#x20;First published on [Cnblogs](https://www.cnblogs.com/mengzhishanghun) · Unauthorized reproduction prohibited

***

The simplest way to start a listen server is to create a desktop shortcut and change its target to UnrealEditor.exe MyProject.uproject ?listen -game.

To join, simply replace the ?listen launch argument with the IP address. Note that there is no - before it.

You can also connect through a listen server directly inside the editor.

The server command is open LevelName?listen.

The client command is open ServerIP.
