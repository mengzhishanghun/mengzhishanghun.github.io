# A Complete Guide to UE Network Programming: UDP, TCP, and WebSocket Implementations

## Introduction

The three most commonly used network communication protocols in UE development are **UDP, TCP, and WebSocket**. They cover most scenarios: UDP suits high-frequency, low-latency transmission, TCP provides reliable two-way communication, and WebSocket excels at real-time cross-platform interaction.

This article demonstrates basic implementations of these three protocols in UE to help you learn the core techniques of UE network programming.

> Note: UE already provides native Blueprint HTTP support (the `Send Http Request` node), so it is not discussed here. Other protocols, such as MQTT and gRPC, can be implemented with third-party libraries as needed.

* * *

## 1. UDP Communication: High-Frequency, Low-Latency Scenarios

### 1.1 Use Cases

-   Sensor data collection (LiDAR, Camera, GPS)
-   Simulator integration (CarSim, PreScan)
-   LAN broadcast/multicast
-   Real-time control commands

### 1.2 Basic Implementation

**Create a UDP Socket and bind a port:**

```cpp
#include "Sockets.h"
#include "SocketSubsystem.h"

// 获取Socket子系统
ISocketSubsystem* SocketSubsystem = ISocketSubsystem::Get(PLATFORM_SOCKETSUBSYSTEM);

// 创建UDP Socket
FSocket* RecvSocket = SocketSubsystem->CreateSocket(NAME_DGram, TEXT("UDP Receiver"), false);

// 创建地址并绑定
TSharedRef<FInternetAddr> Addr = SocketSubsystem->CreateInternetAddr();
Addr->SetPort(8888);
Addr->SetAnyAddress();

if (RecvSocket->Bind(*Addr))
{
    UE_LOG(LogTemp, Log, TEXT("UDP Socket绑定成功,端口: 8888"));
}

// 设置非阻塞模式
RecvSocket->SetNonBlocking(true);
```

**Receive UDP data:**

```cpp
void ReceiveUDPData(FSocket* RecvSocket)
{
    ISocketSubsystem* SocketSubsystem = ISocketSubsystem::Get(PLATFORM_SOCKETSUBSYSTEM);

    TArray<uint8> RecvData;
    RecvData.SetNumUninitialized(65507); // UDP最大包大小

    int32 BytesRead = 0;
    TSharedRef<FInternetAddr> SenderAddr = SocketSubsystem->CreateInternetAddr();

    if (RecvSocket->RecvFrom(RecvData.GetData(), RecvData.Num(), BytesRead, *SenderAddr))
    {
        RecvData.SetNum(BytesRead);

        FString SenderIP = SenderAddr->ToString(false);
        int32 SenderPort = SenderAddr->GetPort();

        UE_LOG(LogTemp, Log, TEXT("收到来自 %s:%d 的数据,大小: %d"),
            *SenderIP, SenderPort, BytesRead);

        // 处理接收到的数据
        ProcessReceivedData(RecvData);
    }
}
```

**Send UDP data:**

```cpp
void SendUDPData(const FString& TargetIP, int32 TargetPort, const TArray<uint8>& Data)
{
    ISocketSubsystem* SocketSubsystem = ISocketSubsystem::Get(PLATFORM_SOCKETSUBSYSTEM);
    FSocket* SendSocket = SocketSubsystem->CreateSocket(NAME_DGram, TEXT("UDP Sender"), false);

    TSharedRef<FInternetAddr> RemoteAddr = SocketSubsystem->CreateInternetAddr();
    bool bIsValid;
    RemoteAddr->SetIp(*TargetIP, bIsValid);
    RemoteAddr->SetPort(TargetPort);

    if (bIsValid)
    {
        int32 BytesSent = 0;
        SendSocket->SendTo(Data.GetData(), Data.Num(), BytesSent, *RemoteAddr);

        UE_LOG(LogTemp, Log, TEXT("发送 %d 字节到 %s:%d"), BytesSent, *TargetIP, TargetPort);
    }

    SendSocket->Close();
    ISocketSubsystem::Get()->DestroySocket(SendSocket);
}
```

## 2. TCP Communication: Reliable Two-Way Transmission

### 2.1 Use Cases

-   Connecting to external servers (Python/C# toolchains)
-   Reliable command transmission (no packet loss allowed)
-   File transfer and resource downloads
-   Scenarios requiring two-way communication

### 2.2 Basic TCP Client Implementation

**Connect to a server:**

```cpp
bool ConnectToTCPServer(const FString& IP, int32 Port)
{
    ISocketSubsystem* SocketSubsystem = ISocketSubsystem::Get(PLATFORM_SOCKETSUBSYSTEM);

    // 创建TCP Socket
    FSocket* ClientSocket = SocketSubsystem->CreateSocket(NAME_Stream, TEXT("TCP Client"), false);

    // 设置目标地址
    TSharedRef<FInternetAddr> Addr = SocketSubsystem->CreateInternetAddr();
    bool bIsValid;
    Addr->SetIp(*IP, bIsValid);
    Addr->SetPort(Port);

    if (!bIsValid)
    {
        UE_LOG(LogTemp, Error, TEXT("无效的IP地址: %s"), *IP);
        return false;
    }

    // 连接
    if (ClientSocket->Connect(*Addr))
    {
        UE_LOG(LogTemp, Log, TEXT("TCP连接成功: %s:%d"), *IP, Port);
        return true;
    }
    else
    {
        UE_LOG(LogTemp, Error, TEXT("TCP连接失败"));
        return false;
    }
}
```

**Send and receive data:**

```cpp
// 发送
bool SendTCPData(FSocket* Socket, const TArray<uint8>& Data)
{
    int32 BytesSent = 0;
    return Socket->Send(Data.GetData(), Data.Num(), BytesSent);
}

// 接收
bool ReceiveTCPData(FSocket* Socket, TArray<uint8>& OutData)
{
    uint32 PendingDataSize = 0;
    if (Socket->HasPendingData(PendingDataSize))
    {
        OutData.SetNumUninitialized(PendingDataSize);
        int32 BytesRead = 0;

        if (Socket->Recv(OutData.GetData(), OutData.Num(), BytesRead))
        {
            OutData.SetNum(BytesRead);
            return true;
        }
    }
    return false;
}
```

### 2.3 Basic TCP Server Implementation

**Listen on a port:**

```cpp
bool StartTCPServer(int32 Port)
{
    ISocketSubsystem* SocketSubsystem = ISocketSubsystem::Get(PLATFORM_SOCKETSUBSYSTEM);

    // 创建监听Socket
    FSocket* ListenSocket = SocketSubsystem->CreateSocket(NAME_Stream, TEXT("TCP Server"), false);

    // 绑定端口
    TSharedRef<FInternetAddr> Addr = SocketSubsystem->CreateInternetAddr();
    Addr->SetPort(Port);
    Addr->SetAnyAddress();

    if (!ListenSocket->Bind(*Addr))
    {
        UE_LOG(LogTemp, Error, TEXT("绑定端口失败: %d"), Port);
        return false;
    }

    // 开始监听(最大8个待连接队列)
    if (!ListenSocket->Listen(8))
    {
        UE_LOG(LogTemp, Error, TEXT("监听失败"));
        return false;
    }

    UE_LOG(LogTemp, Log, TEXT("TCP服务器启动,端口: %d"), Port);
    return true;
}
```

**Accept client connections:**

```cpp
void AcceptClients(FSocket* ListenSocket)
```

## 3. WebSocket: Modern Cross-Platform Communication

### 3.1 Use Cases

-   Web frontend control panels
-   Real-time cloud-service push notifications
-   Communication with browsers/mobile devices
-   A unified protocol across languages and platforms

### 3.2 UE's Built-in WebSocket Module

UE provides the `WebSockets` module. Add it to `.Build.cs`:

```csharp
PublicDependencyModuleNames.AddRange(new string[] {
    "Core",
    "WebSockets",
    "Http"
});
```

### 3.3 Basic Implementation

**Connect to WebSocket:**

```cpp
#include "IWebSocket.h"
#include "WebSocketsModule.h"

void ConnectWebSocket(const FString& URL)
{
    // 创建WebSocket实例
    TSharedPtr<IWebSocket> WebSocket = FWebSocketsModule::Get().CreateWebSocket(URL);

    // 绑定连接成功事件
    WebSocket->OnConnected().AddLambda([]()
    {
        UE_LOG(LogTemp, Log, TEXT("WebSocket连接成功"));
    });

    // 绑定消息接收事件
    WebSocket->OnMessage().AddLambda([](const FString& Message)
    {
        UE_LOG(LogTemp, Log, TEXT("收到消息: %s"), *Message);
    });

    // 绑定连接关闭事件
    WebSocket->OnClosed().AddLambda([](int32 StatusCode, const FString& Reason, bool bWasClean)
    {
        UE_LOG(LogTemp, Warning, TEXT("WebSocket关闭: %s"), *Reason);
    });

    // 发起连接
    WebSocket->Connect();
}
```

**Send messages:**

```cpp
void SendWebSocketMessage(TSharedPtr<IWebSocket> WebSocket, const FString& Message)
{
    if (WebSocket.IsValid() && WebSocket->IsConnected())
    {
        WebSocket->Send(Message);
    }
}
```

**Notes:**

-   Use `127.0.0.1` instead of `localhost` after packaging to avoid name-resolution issues
-   UE's WebSocket module supports only `ws://`, not encrypted `wss://`
-   Connection URL format: `ws://127.0.0.1:8080`

## 4. A More Complete Approach for Real Projects

The code above shows basic network communication, but real projects often require a fuller architecture:

-   **Multiple channels**—different ports handle different business logic
-   **Asynchronous threads**—avoid blocking the game thread
-   **Automatic reconnection**—TCP clients retry after disconnection
-   **Session management**—TCP servers distinguish clients
-   **IP filtering**—allowlists/denylists with CIDR support
-   **Blueprint support**—complete Blueprint node wrappers
-   **Data serialization**—two-way conversion between structs and byte arrays

## Summary

The core of UE network communication is:

1.  **Choose the right protocol**—UDP (high frequency and low latency) / TCP (reliable transmission) / WebSocket (cross-platform)
2.  **Master the basics**—understand the underlying logic of creating Sockets and sending and receiving data
3.  **Complete the architecture**—real projects need asynchronous processing, multiple channels, Blueprint support, and more

This article provides basic implementation code to explain the principles of UE network communication.

With the principles explained, you can try implementing a complete network communication solution yourself. It is also a good learning opportunity.
