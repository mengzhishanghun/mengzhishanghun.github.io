# Making Conda Available in CMD Without Exposing Python from the Default Environment

# Why Do This?

After installing Miniconda, the system normally uses its base environment by default and can run Python directly from it, making base very easy to contaminate.

What I need is for CMD to recognize the conda command normally without recognizing python.

# Step One

Make sure Python is not installed in the machine's main environment. Download and install Miniconda, select just me during installation, and do not set environment variables.

# Step Two

Open a CMD window and use the absolute path to run conda init.

```
C:\Users\mengzhishanghun\miniconda3\Scripts\conda.exe init cmd.exe

```

Open a new CMD window, and you will find that CMD now recognizes conda commands correctly.

# Step Three

Now enter:

```
conda config --set auto_activate_base false
```

This disables automatic entry into the base environment. At this point, entering where python returns:

```
C:\Users\mengzhishanghun>where python
信息: 用提供的模式无法找到文件。
```
