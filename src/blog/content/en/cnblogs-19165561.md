UE: Synchronizing Exposure Across Multiple Screens
===

The very, very simplest method is

Create a new LocalPlayer and override the function\
&#x20;![](/media-occurrence/blog%3Acnblogs-19165561%3Amedia%3A1)

The implementation is below\
&#x20;![](/media-occurrence/blog%3Acnblogs-19165561%3Amedia%3A2)

The principle here is to set StereoPass to eSSP_SECONDARY for all players other than the primary player

During rendering, the system will then treat them as the left and right eyes of the same pair and use the same data to calculate exposure. This synchronization is absolute, with no deviation

In version 5.3.2, this code is in the FSceneView constructor\
