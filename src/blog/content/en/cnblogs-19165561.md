# Synchronizing Exposure Across Multiple Screens

The very simplest method is:

Create a LocalPlayer and override the function.
![](/media-occurrence/blog%3Acnblogs-19165561%3Amedia%3A1)

Here is the implementation:
![](/media-occurrence/blog%3Acnblogs-19165561%3Amedia%3A2)

The principle is to set StereoPass to eSSP_SECONDARY for all players other than the primary player.

During rendering, the system then treats them as the left and right views of the same eye setup and uses the same data to calculate exposure. This synchronization is exact, with no deviation.

In version 5.3.2, the relevant code is in FSceneView's constructor.
![](/media-occurrence/blog%3Acnblogs-19165561%3Amedia%3A3)
