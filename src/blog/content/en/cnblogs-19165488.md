UE: Fixing Missing Context in UObject Blueprints
===

# Problem Overview

Normally, when you create a Blueprint derived from UObejct, you will find that you cannot get the PlayerController

![](/media-occurrence/blog%3Acnblogs-19165488%3Amedia%3A1)

You also cannot create UI without an error

![](/media-occurrence/blog%3Acnblogs-19165488%3Amedia%3A2)

This happens because the parent class does not override GetWorld, so the Blueprint compiler cannot obtain the context, causing an error.

# Solution

Once the cause is known, the problem is easy to solve: simply override GetWorld in the parent class. However, there are a few things to keep in mind

Add this in the .h file

```C++
virtual UWorld* GetWorld() const override;

```

Add this in the .cpp file

```C++
UWorld* UAIFlow::GetWorld() const  
{  
    if (IsTemplate() || !GetOuter())  
    {  
       return nullptr;  
    }  
  
    return GetOuter()->GetWorld();  
}

```

Note that you cannot simply return directly here; that will not directly solve the problem. It must be written this way.

In this case, I create the object in an Actor, so GetOuter points directly to that Actor, allowing me to get GetWorld correctly. You therefore need to write the return here according to your own situation.
