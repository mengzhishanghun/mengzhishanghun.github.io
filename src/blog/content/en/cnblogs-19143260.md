# What to Do When a Stream Depot Cannot Be Deleted

# First, List the Current Streams

Use this command:

```
p4 streams -a
```

![](/media-occurrence/blog%3Acnblogs-19143260%3Amedia%3A1)

Both test and Unreal Depot are depots I want to delete. test is intact, while the other was first deleted with stream -f -d and marked deleted, yet the depot still cannot be deleted.

# Force Deletion

Use this command to force deletion:

```
p4 stream -d --obliterate -y -f //test/UEPublic/test1
```

![](/media-occurrence/blog%3Acnblogs-19143260%3Amedia%3A2)

That does it. Return to p4admin and delete the Depot.

# The Message “has active clients; cannot delete until they are removed.”

This means a workspace is still using the Stream. Find that workspace and delete it or switch it to another Stream.
