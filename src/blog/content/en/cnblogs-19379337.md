# Material Basics: The If Node

![](/media-occurrence/blog%3Acnblogs-19379337%3Amedia%3A1)

A beginner in our group shared this image a couple of days ago and asked why the material is invisible when dissolve is 0.

I have some free time today, so here is a short explanation.

Let's examine each part.

The dissolve node in the upper-left is a parameter that receives a value from outside, such as a material instance. It outputs a float, which can be changed dynamically in a material instance and elsewhere. This is one of the keys to changing materials dynamically.

TextureSample is a texture node with six outputs, all representing the same underlying data. You probably know the three primary colors: red, green, and blue. These are its RGB—Red, Green, Blue—while A represents transparency.

What do the six outputs mean? RGB outputs a vector3f, like (Red,Green,Blue). R, G, B, and A are the red, green, blue, and alpha channel values respectively; each is a float in [0,1]. The final RGBA is therefore a vector4f, with an A channel added to RGB, in a format like (R,G,B,A).

Next is the only control-logic node in the screenshot: IF. If you have studied programming, you know it means “if this, then that.” This node has five inputs and one output: parameter A, parameter B, the output when A is less than B, the output when A equals B, and the output when A is greater than B.

The graph compares dissolve with the texture's red-channel value. Given dissolve is 0 and the red channel is in [0,1], A is always less than or equal to B. The result is therefore always 0; the opacity mask is 0, making the material invisible.
