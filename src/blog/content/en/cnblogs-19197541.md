# The Keys to Runtime Animation Recording: Correct Bone Data and Saving

## Core Issues

The two most important issues in runtime animation recording in UE5.4 are:
1. **Obtaining correct bone data**—avoiding crashes and data mismatches
2. **Saving AnimSequence correctly**—using standard engine APIs

This article goes straight to the essentials with a concise, effective solution.

---

## 1. Obtaining Correct Bone Data

### Core Principle: Use Three Key APIs Correctly

```cpp
// ✅ 正确：使用 SkeletalMesh 的 RefSkeleton
USkeletalMesh* SkeletalMesh = SkeletalMeshComponent->GetSkeletalMeshAsset();
const FReferenceSkeleton& RefSkeleton = SkeletalMesh->GetRefSkeleton();

// ✅ 正确：使用 GetRawBoneNum() 获取实际骨骼数
const int32 NumBones = RefSkeleton.GetRawBoneNum();

// ✅ 正确：运行时变换数据
const TArray<FTransform>& BoneSpaceTransforms = SkeletalMeshComponent->GetBoneSpaceTransforms();
```

### Incorrect Examples and Consequences

| Incorrect code | Problem | Consequence |
|----------|------|------|
| `Skeleton->GetReferenceSkeleton()` | Includes ControlRig virtual bones | Crash: FKControlRig.cpp:126 |
| `RefSkeleton.GetNum()` | Returns all bones, including virtual ones | Array out of bounds |
| Calling `GetBoneNames()` and then iterating RefSkeleton | Adds bone names twice | Inconsistent data |

### Key API Comparison

| Data source | Method | Example return value | Correct? |
|--------|------|------------|----------|
| `Skeleton->GetReferenceSkeleton().GetNum()` | All bones | 161 (89 actual + 72 virtual) | ❌ |
| `SkeletalMesh->GetRefSkeleton().GetNum()` | All bones | 161 | ❌ |
| `SkeletalMesh->GetRefSkeleton().GetRawBoneNum()` | Actual bones | 89 | ✅ |
| `SkeletalMeshComponent->GetBoneSpaceTransforms().Num()` | Runtime transforms | 89 | ✅ For comparison and verification |

**AnimSequence.cpp, lines 2674–2678 (official implementation)**:

### Complete Initialization Code

```cpp
void ATestActor::StartRecording(int _FrameSize, ACharacter* _TargetActor)
{
    TargetActor = _TargetActor;
    SkeletalMeshComponent = TargetActor->GetMesh();

    // 1. 获取正确的 RefSkeleton（SkeletalMesh 的，不是 Skeleton 的）
    USkeletalMesh* SkeletalMesh = SkeletalMeshComponent->GetSkeletalMeshAsset();
    const FReferenceSkeleton& RefSkeleton = SkeletalMesh->GetRefSkeleton();

    // 2. 使用 GetRawBoneNum() 获取实际骨骼数
    const int32 NumBones = RefSkeleton.GetRawBoneNum();

    // 3. 获取运行时变换数据（用于验证）
    const TArray<FTransform>& BoneSpaceTransforms = SkeletalMeshComponent->GetBoneSpaceTransforms();

    // 4. 安全性检查（引擎期望这个条件）
    if (BoneSpaceTransforms.Num() < NumBones)
    {
        UE_LOG(LogTemp, Error, TEXT("骨骼数据不匹配：BoneSpaceTransforms(%d) < RawBoneNum(%d)"),
            BoneSpaceTransforms.Num(), NumBones);
        return;
    }

    // 5. 填充骨骼名称（单次遍历）
    BoneNames.Empty();
    for (int32 BoneIndex = 0; BoneIndex < NumBones; ++BoneIndex)
    {
        BoneNames.Add(RefSkeleton.GetBoneName(BoneIndex));
    }

    // 6. 初始化数据数组
    TrackDataArray.SetNum(NumBones);
    IsRecording = true;
}
```

### Key Points Explained

#### Why Must You Use the SkeletalMesh's RefSkeleton?

```cpp
// ❌ 错误：Skeleton 的 RefSkeleton 包含 ControlRig 虚拟骨骼
const FReferenceSkeleton& RefSkeleton =
    SkeletalMesh->GetSkeleton()->GetReferenceSkeleton();  // 161个骨骼

// ✅ 正确：SkeletalMesh 的 RefSkeleton 是实际骨骼层级
const FReferenceSkeleton& RefSkeleton =
    SkeletalMesh->GetRefSkeleton();  // 配合 GetRawBoneNum() 使用
```

**Examples of virtual bones in Skeleton**:
- `root_CONTROL`—ControlRig root controller
- `ik_hand_l_CONTROL`—IK hand controller
- These bones **do not exist** in `BoneSpaceTransforms`!

#### Why Must You Use GetRawBoneNum()?

```cpp
// GetNum() vs GetRawBoneNum() 的区别
RefSkeleton.GetNum();         // 返回全部：RawBones + VirtualBones = 161
RefSkeleton.GetRawBoneNum();  // 返回实际：RawBones = 89
```

**Verification method**:
```cpp
UE_LOG(LogTemp, Warning, TEXT("RefSkeleton.GetNum() = %d"), RefSkeleton.GetNum());
UE_LOG(LogTemp, Warning, TEXT("RefSkeleton.GetRawBoneNum() = %d"), RefSkeleton.GetRawBoneNum());
UE_LOG(LogTemp, Warning, TEXT("BoneSpaceTransforms.Num() = %d"), BoneSpaceTransforms.Num());

// 正确结果应该是：
// GetNum() = 161
// GetRawBoneNum() = 89
// BoneSpaceTransforms.Num() = 89
```

## 2. Saving AnimSequence Correctly

### Core Principle: Use IAnimationDataController

UE5 deprecated direct modification of AnimSequence; changes must go through the `IAnimationDataController` interface.

### Standard Save Workflow (5 Key Steps)

```cpp
void ATestActor::SpawnAnimAsset()
{
    // === 1. 创建资产对象 ===
    UPackage* Package = CreatePackage(*AssetPath);
    UAnimSequence* AnimSeq = NewObject<UAnimSequence>(Package, UAnimSequence::StaticClass(),
        *AssetName, RF_Public | RF_Standalone | RF_MarkAsRootSet);

    // 绑定 Skeleton
    USkeletalMesh* SkeletalMesh = SkeletalMeshComponent->GetSkeletalMeshAsset();
    AnimSeq->SetSkeleton(SkeletalMesh->GetSkeleton());

    // === 2. 获取 Controller（唯一修改接口）===
    IAnimationDataModel* Model = AnimSeq->GetDataModel();
    TScriptInterface<IAnimationDataController> Controller = Model->GetController();

    // === 3. 初始化模型（使用 FScopedBracket）===
    Controller->InitializeModel();
    IAnimationDataController::FScopedBracket ScopedBracket(Controller,
        LOCTEXT("RecordAnimation", "Recording Animation"));

    // === 4. 设置帧率和帧数 ===
    // 计算实际帧率（关键：不能用固定值）
    float RecordingDuration = GetWorld()->GetTimeSeconds() - RecordingStartTime;
    int32 NumFrames = TrackDataArray[0].PosKeys.Num();
    float ActualFrameRate = (float)NumFrames / RecordingDuration;
    ActualFrameRate = FMath::Clamp(ActualFrameRate, 24.0f, 120.0f);

    Controller->SetFrameRate(FFrameRate(FMath::RoundToInt(ActualFrameRate), 1));
    Controller->SetNumberOfFrames(NumFrames);

    // === 5. 添加骨骼轨道和关键帧 ===
    for (int32 BoneIndex = 0; BoneIndex < BoneNames.Num(); ++BoneIndex)
    {
        const FName& BoneName = BoneNames[BoneIndex];
        const FRawAnimSequenceTrack& Track = TrackDataArray[BoneIndex];

        // 5.1 添加骨骼曲线
        Controller->AddBoneCurve(BoneName);

        // 5.2 准备 Scale 数据（引擎要求 Pos/Rot/Scale 数量一致）
        TArray<FVector3f> ScaleKeys;
        ScaleKeys.Init(FVector3f(1.0f, 1.0f, 1.0f), Track.PosKeys.Num());

        // 5.3 设置关键帧
        Controller->SetBoneTrackKeys(BoneName, Track.PosKeys, Track.RotKeys, ScaleKeys);
    }

    // 5.4 通知数据填充完成（必须调用）
    Controller->NotifyPopulated();

    // === 6. 启用根骨骼运动（可选）===
    AnimSeq->bEnableRootMotion = true;
    AnimSeq->RootMotionRootLock = ERootMotionRootLock::RefPose;

    // === 7. 保存资产 ===
    FAssetRegistryModule::AssetCreated(AnimSeq);
    Package->MarkPackageDirty();

    FString PackageFileName = FPackageName::LongPackageNameToFilename(
        AssetPath, FPackageName::GetAssetPackageExtension());
    FSavePackageArgs SaveArgs;
    bool bSaved = UPackage::SavePackage(Package, AnimSeq, *PackageFileName, SaveArgs);
}
```

### API Comparison: UE4 versus UE5

| Functionality | UE4 (deprecated) | UE5 (standard) |
|------|---------------|-------------|
| Adding tracks | `AddNewRawTrack()` | `Controller->AddBoneCurve()` |
| Setting keyframes | Directly modify RawAnimationData | `Controller->SetBoneTrackKeys()` |
| Scope management | `OpenBracket()` / `CloseBracket()` | `FScopedBracket` (RAII) |
| Completion notification | None | `Controller->NotifyPopulated()` |

### Key Steps Explained

#### Step 3: Why Use FScopedBracket?

```cpp
// ❌ UE4 旧方式（容易忘记 CloseBracket）
Controller->OpenBracket(LOCTEXT("AddTracks", "Adding Tracks"));
// ... 添加数据
Controller->CloseBracket();  // 如果中途 return 会泄漏

// ✅ UE5 标准方式（RAII 自动管理）
{
    IAnimationDataController::FScopedBracket ScopedBracket(Controller, LOCTEXT(...));
    // ... 添加数据
}  // 离开作用域自动调用 CloseBracket
```

#### Step 4: Why Not Use a Fixed Frame Rate?

```cpp
// ❌ 错误：固定 30fps
Controller->SetFrameRate(FFrameRate(30, 1));
// 如果游戏运行在 60fps，录制的动画会以 2 倍速播放！

// ✅ 正确：动态计算
float ActualFrameRate = (float)NumFrames / RecordingDuration;
Controller->SetFrameRate(FFrameRate(FMath::RoundToInt(ActualFrameRate), 1));
```

#### Step 5.4: What Does NotifyPopulated() Do?

```cpp
Controller->NotifyPopulated();  // ← 必须调用！
```

**Purpose**:
- Notifies the engine that data population is complete
- Triggers internal cache updates
- Verifies data integrity
- **Omitting it prevents the animation from playing**

### Tick Recording Logic

```cpp
void ATestActor::Tick(float DeltaTime)
{
    Super::Tick(DeltaTime);

    if (IsRecording)
    {
        const TArray<FTransform>& BoneSpaceTransforms = SkeletalMeshComponent->GetBoneSpaceTransforms();

        // 计算相对位移（用于根骨骼运动）
        FTransform CurrentActorTransform = TargetActor->GetActorTransform();
        FTransform RelativeActorTransform = CurrentActorTransform.GetRelativeTransform(InitialActorTransform);

        for (int i = 0; i < BoneNames.Num(); ++i)
        {
            FTransform FinalBoneTransform;

            if (i == 0)  // 根骨骼
            {
                // 烘焙世界位移到根骨骼
                FinalBoneTransform = BoneSpaceTransforms[0] * RelativeActorTransform;
            }
            else
            {
                FinalBoneTransform = BoneSpaceTransforms[i];
            }

            TrackDataArray[i].PosKeys.Add(FVector3f(FinalBoneTransform.GetLocation()));
            TrackDataArray[i].RotKeys.Add(FQuat4f(FinalBoneTransform.GetRotation()));
            TrackDataArray[i].ScaleKeys.Add(FVector3f(FinalBoneTransform.GetScale3D()));
        }
    }
}
```

## 4. Core Technical Points

### Obtaining Bone Data (3 Requirements)

| Step | API | Consequence of an error |
|------|-----|------------|
| 1. Data source | `SkeletalMesh->GetRefSkeleton()` | Using Skeleton includes virtual bones |
| 2. Bone count | `RefSkeleton.GetRawBoneNum()` | Using GetNum() causes out-of-bounds access |
| 3. Validation | `BoneSpaceTransforms.Num() >= NumBones` | Failing to check causes crashes |

### Saving AnimSequence (5 Key Points)

| Step | API | Purpose |
|------|-----|------|
| 1. Obtain Controller | `Model->GetController()` | The only modification interface |
| 2. Manage scope | `FScopedBracket` | Automatic RAII cleanup |
| 3. Add tracks | `AddBoneCurve()` | Standard UE5 API |
| 4. Set data | `SetBoneTrackKeys()` | Pos/Rot/Scale counts must match |
| 5. Notify completion | `NotifyPopulated()` | Must be called |

## Conclusion

The essentials of runtime animation recording in UE5.4 are:

1. **Obtaining correct bone data**:
   - Use `SkeletalMesh->GetRefSkeleton()` rather than the Skeleton's
   - Use `GetRawBoneNum()` rather than `GetNum()`
   - Always validate `BoneSpaceTransforms.Num() >= NumBones`

2. **Saving AnimSequence correctly**:
   - Work through the `IAnimationDataController` interface
   - Manage scope with `FScopedBracket`
   - Call `AddBoneCurve()` rather than `AddBoneTrack()`
   - Always call `NotifyPopulated()`

Following these principles enables a stable, reliable animation recording system.
