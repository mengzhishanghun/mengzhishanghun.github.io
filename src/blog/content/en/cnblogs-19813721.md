# Fixing UMG Size That Does Not Change During Rendering

When rendering UMG, you may encounter a frustrating issue: its rendered size does not change with the output resolution you set.

The solution is simple, though annoying: open Project Settings, find the following option, and enable it.

![](/media-occurrence/blog%3Acnblogs-19813721%3Amedia%3A1)

Alternatively, add this to DefaultEditor.ini:

~~~
[/Script/MovieRenderPipelineEditor.MoviePipelinePIEExecutorSettings]

bResizePIEWindowToOutputResolution=True
~~~
