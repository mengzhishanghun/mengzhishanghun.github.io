# UE Source Control Operations Guide

Operations in Unreal are much like those in Perforce.

The main differences are that Unreal has a built-in Chinese interface and can compare Blueprint differences.

Also, move and rename files in Unreal, because Unreal updates references automatically. Otherwise, references may break.

After moving or renaming files, right-click and fix up redirectors manually.

Since Unreal's interface is in Chinese, I will focus on a few precautions rather than explain every operation here.

# Connecting to a Perforce Server

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A1)

Open the Unreal Editor and click Version Control → Connect to Source Control in the lower-right corner.

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A2)

Select Perforce, enter the server address and username, and let it search for workspaces automatically. Select an available workspace and click Accept Settings.

# Perforce Operations

All Perforce operations are collected here.

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A3)

To submit, choose View Changes under Version Control in the lower-right corner. This shows all changelists, which you can submit as needed.

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A4)

# Asset Control

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A5)

A red check mark means the file is checked out. If you checked it out by mistake, choose Revert rather than Check In.

A green plus means the file is marked for addition to version control.

A red X means the file will be deleted.
