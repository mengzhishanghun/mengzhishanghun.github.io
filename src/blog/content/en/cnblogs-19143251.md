Perforce: Source Control Operations in UE
===

> © [mengzhishanghun](https://github.com/mengzhishanghun) · Original article\
> &#x20;First published on [Cnblogs](https://www.cnblogs.com/mengzhishanghun) · Unauthorized reproduction prohibited

***

Operations in Unreal are largely the same as those in Perforce

The main differences are that Unreal has built-in Chinese support and can compare Blueprint differences

Also, be sure to move and rename files in Unreal, because Unreal automatically updates references; otherwise, reference errors may occur

After moving or renaming files, right-click and use Fix Up Redirectors to fix redirects manually

Since Unreal's interface is in Chinese, I will not go into much detail here and will only cover a few things to keep in mind

# Connecting to a Perforce Server

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A1)

Open the Unreal Editor and click Source Control -> Connect to Source Control in the bottom-right corner

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A2)

Select Perforce, enter the server address and username, and workspaces will be found automatically. Select an available workspace and click Accept Settings

# Perforce Operations

All Perforce operations are collected here

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A3)

To submit, select View Changes under Source Control in the bottom-right corner to see all changelists, then submit as needed

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A4)

# Asset Control

![](/media-occurrence/blog%3Acnblogs-19143251%3Amedia%3A5)

A red check mark means the file is checked out. If you checked it out accidentally, do not click Check In; click Revert instead

A green plus means the file is marked for addition to source control

A red X means the file will be deleted
