# Tips for Chinese and English Editor Settings

There seem to be many new UE users lately, so I am collecting a few tips for everyone.

This time, the topic is making Blueprint functions as convenient as possible while keeping the UE editor in Chinese.

The settings are simple. Follow along.

![](/media-occurrence/blog%3Acnblogs-19183986%3Amedia%3A1)

![](/media-occurrence/blog%3Acnblogs-19183986%3Amedia%3A2)

These options are enabled by default, causing function names and the Details panel to display Chinese. That makes both searching and calling functions extremely inconvenient.

I recommend disabling all three checkboxes.

Functions then appear as follows:
![](/media-occurrence/blog%3Acnblogs-19183986%3Amedia%3A3)

The Details panel appears as follows:

![](/media-occurrence/blog%3Acnblogs-19183986%3Amedia%3A4)

This makes calling functions and searching source code easier, while Chinese explanations still appear on hover in most cases, helping beginners learn.

UE has so many features that, unless your English is very good, I recommend this approach. It greatly improves development efficiency, helps beginners get started and adapt sooner, and prepares them well for moving to an entirely English interface later.

These editor changes are global. You only need to make them once for each new version, and I recommend beginners do so as soon as they open the engine.
