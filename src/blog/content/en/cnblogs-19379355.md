# Making a Rounded Rectangle with a Material

I cannot even remember when I wrote this; I found it while organizing my notes. It creates a rounded rectangle with a material. Because it was intended for a project with three combined screens, the values were set for those three screens. Adjust them before using it.

## Approach
Use UE's built-in GeneratedRoundRect function to make a rounded rectangle, then subtract a smaller one to create its border.
![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A3)
Pass in the UV, rectangle size, corner radius, default value, and center point respectively.
Since the rounded rectangle must scale, account for the screen aspect ratio.
![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A4)
A normal screen is 16:9; this project uses three screens, so it is 48:9.
Keep the following in mind:
![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A5)
The smaller rectangle's size is the larger rectangle's size minus the border size.
The smaller corner radius is the larger radius minus the border size.
