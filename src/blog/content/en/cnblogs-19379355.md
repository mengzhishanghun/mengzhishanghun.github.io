I cannot even remember when I wrote this down. I came across it while organizing my notes. It creates a rounded rectangle with a material. Since it was intended for a project using three monitors combined into one screen, the values were set for three monitors. Please remember to adjust them if you use this.

## Approach

Use UE's built-in GeneratedRoundRect function to create a rounded rectangle, then subtract a smaller one to create a rounded rectangle border.\
&#x20;![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A3)\
&#x20;Pass in the UV, rectangle size, corner radius, default value, and center point respectively.\
&#x20;Because the rounded rectangle needs to be scalable, the screen's aspect ratio must be considered.\
&#x20;![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A4)\
&#x20;A normal screen is 16:9. This project uses three monitors, so the ratio is 48:9.\
&#x20;Note that:\
&#x20;![](/media-occurrence/blog%3Acnblogs-19379355%3Amedia%3A5)\
&#x20;The smaller rectangle's size is the larger rectangle's size minus the border size.\
&#x20;The smaller corner radius is the larger corner radius minus the border size.
