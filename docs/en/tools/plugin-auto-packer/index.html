UEPluginAutoPacker

Multi-version UE plugin packaging

Multi-version UE plugin packaging。

Features

Section titled “Features”
  • Manage multiple Unreal Engine versions
  • Run packaging from the GUI or CLI
  • Review logs and prepare Fab output

Quick start

Section titled “Quick start”
  1. Get the Windows executable from Releases.
  2. Place it in a project directory with a .uproject file and configure engines and plugins using the README.
  3. Run packaging and review the logs. Check the final files before publishing.
