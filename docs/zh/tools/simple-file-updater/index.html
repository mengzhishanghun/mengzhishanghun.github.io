SimpleFileUpdater 使用指南（本地键值对版本）

SimpleFileUpdater 是一个轻量级的文件同步工具，适用于希望从远程地址批量更新本地文件的用户。程序已打包为 SimpleFileUpdater.exe，支持通过配置文件定义目标文件及其下载地址。
