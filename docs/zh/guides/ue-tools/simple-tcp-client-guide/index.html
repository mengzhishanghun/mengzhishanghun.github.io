SimpleTCPClient 使用文档

SimpleTCPClient 的完整中文产品使用文档

SimpleTCPClient 是一个为 Unreal Engine 设计的轻量级 TCP 客户端插件。
支持运行时动态配置客户端通道，所有功能均暴露给蓝图，方便集成。

兼容性

Section titled “兼容性”
  • Unreal Engine 5.2–5.8
  • 版本 1.1.0（Version 2）
  • 更新日志（公开仓库暂无此文件）

🔧 插件初始化

Section titled “🔧 插件初始化”

插件启用后自动激活。
内部注册为 GameInstanceSubsystem，无需手动启动或关闭代码。

⚙️ 静态通道配置（可选）

Section titled “⚙️ 静态通道配置（可选）”

可通过 项目设置 → SimpleTCPClient Settings 预定义客户端通道。
建议在此处配置通道，便于集中管理。

🔹 客户端通道配置字段

Section titled “🔹 客户端通道配置字段”
字段示例说明
Channel NameDefaultClient蓝图中引用通道的名称
Remote Address (IP:Port)127.0.0.1:8888要连接的目标地址
Auto ConnectTrue是否在启动时自动连接
Auto Reconnect Interval1.0（秒）重连尝试间隔
Max Receive Bytes1024每次接收的最大字节数

⚙️ 运行时通道管理

Section titled “⚙️ 运行时通道管理”
节点函数说明
StartConnection手动启动连接（用于非自动连接的通道）
StopConnection停止并销毁 Socket
IsConnected检查通道当前是否已连接
UpdateTCPClientConfig创建或更新通道配置（自动重连）
GetTCPClientConfig获取通道的当前配置

✅ 提示与注意事项

Section titled “✅ 提示与注意事项”
  • 仅支持 IPv4——不支持域名、IPv6 或加密
  • 所有 Socket 由内部完全管理，无需手动清理
  • 插件存在于 GameInstance 生命周期中，不受关卡切换影响

🔧 推荐配套插件

Section titled “🔧 推荐配套插件”

配合 SimpleByteConversion 使用，可轻松将常见 Unreal 类型（FString、float、int 等）与 TArray<uint8> 互转，构建结构化协议。

Section titled “版本历史”
