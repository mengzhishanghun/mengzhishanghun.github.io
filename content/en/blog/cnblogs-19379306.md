# Seeing Exactly Which Files Were Packaged

# Result

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A1)

These are the files after packaging. Unlike the usual packaged files, this view shows every included configuration file, asset, plugin, and so on.

# Configuration

Using UE5.2 as an example, first open Packaging Settings.

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A2)

![](/media-occurrence/blog%3Acnblogs-19379306%3Amedia%3A3)

Disable Use Pak File and Use Io Store; both are usually enabled by default.

You can then see the packaged project's files.
