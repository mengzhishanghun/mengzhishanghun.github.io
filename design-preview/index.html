解决什么问题

UE 项目打包包含构建、烘焙、文件整理等环节，输出包有时还需要附带额外数据或工具。UEPackageManager 将这些操作放在同一个图形界面与命令行入口中。

主要功能

  • 调用 Unreal Automation Tool 执行 Build、Cook、Stage、Pak 和 Archive。
  • 根据项目目录识别 .uproject 与关联引擎，图形界面绑定当前项目。
  • 项目配置独立保存，避免不同项目复用错误的路径与选项。
  • 打包成功后，按规则复制附加文件或文件夹，并支持递归忽略项。
  • 清理旧包需要单独确认；附加复制仅在打包成功后执行。

使用与适用范围

把 EXE 放到包含 .uproject 的项目根目录，无参数运行打开图形界面，带子命令运行使用 CLI。适用于 Windows / Win64 项目打包；插件独立打包由 UEPluginAutoPacker 负责。
