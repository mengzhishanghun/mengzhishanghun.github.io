MDImageEmbed User Manual

Complete English product manual for MDImageEmbed

MD Image Embed

MDImageEmbed is an Obsidian plugin that converts local images in Markdown files to embedded Base64. It is useful for exporting notes, publishing blog posts, or sharing documents without relying on external image files.

License: MIT Obsidian

Features

Section titled “Features”
  • One-click conversion: Context menu → Copy as Base64 format to the clipboard
  • Smart path resolution: Supports various Obsidian image path formats
  • Anti-reposting protection: Adds custom prefixes/suffixes from template files (v1.1.0)
  • Format support: PNG, JPG, JPEG, GIF, WebP, SVG, BMP
  • Wiki link support: Converts ![[image.png]] to standard Markdown containing Base64

Installation Methods

Section titled “Installation Methods”

Manual Installation

Section titled “Manual Installation”
  1. Download main.js, manifest.json, and styles.css from the latest Release
  2. Create the folder <Vault>/.obsidian/plugins/md-image-embed/
  3. Copy the files into that folder
  4. Restart Obsidian and enable the plugin under Settings → Community Plugins

How to Use

Section titled “Usage”
  1. Right-click any .md file in the Obsidian file explorer
  2. Select Copy as Base64 format
  3. Paste the converted content wherever you need it

Settings

Section titled “Settings”

Configure under Settings → Community Plugins → MD Image Embed:

  • Show conversion logs: Display a conversion summary in notifications
  • Show detailed logs: Display each image’s status in notifications
  • Convert Wiki links: Convert ![[image.png]] to standard Markdown
  • Skip Base64 images: Skip images already converted to Base64
  • Prefix/suffix file paths: Add custom content before and after the article for anti-reposting protection

Anti-Reposting Protection

Section titled “Anti-Reposting Protection”

Add copyright notices or author information:

  1. Create template files such as templates/prefix.md and templates/suffix.md
  2. Enter the file paths in the plugin settings
  3. The content is added automatically when copying

Notes

Section titled “Notes”
  • Only local images are supported; remote URLs are skipped
  • Base64 encoding increases file size by about 33%
  • Recommended only for export/sharing

MDImageEmbed User Guide

Section titled “MDImageEmbed User Guide”

MDImageEmbed is an Obsidian plugin that converts local images to embedded Base64 and copies the result through the context menu. This guide preserves the plugin usage described in the original article.

Installation

Section titled “Installation”

Installation: Download main.js, manifest.json, and styles.css into <Vault>/.obsidian/plugins/md-image-embed/, restart Obsidian, and enable the plugin.

Supported formats: PNG, JPG, JPEG, GIF, WebP, SVG, BMP

Feature Overview

Section titled “Feature Overview”

One-Click Conversion

Section titled “One-Click Conversion”

Right-click a .md file → Copy as Base64 format → paste into the target platform.

Smart Path Resolution

Section titled “Smart Path Resolution”

Supports standard Markdown and Obsidian Wiki link syntax, automatically recognizing various relative paths.

Anti-Reposting Protection

Section titled “Anti-Reposting Protection”

Configure prefix/suffix template files to add copyright notices or author information automatically during conversion.

Smart Filtering

Section titled “Smart Filtering”

Automatically skips remote images and existing Base64 images.

Demonstration: Publishing to CNBlogs

Section titled “Demonstration: Publishing to CNBlogs”

Step 1: Right-click the file in Obsidian and select Copy as Base64 format

Step 2: Paste into the CNBlogs editor and click Extract Images in the lower right

Step 3: Base64 is automatically converted to CNBlogs image-hosting links, completing publication

Usage Boundaries

Section titled “Usage Boundaries”

The target platform must accept Base64 images or provide a way to extract them into platform image assets. Embedding increases text size; keep separate image files for everyday editing.
