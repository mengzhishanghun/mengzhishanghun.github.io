SimpleByteConversion 使用文档

SimpleByteConversion 的完整中文产品使用文档

支持的虚幻引擎版本：5.2–5.8

SimpleByteConversion 是一个为 Unreal Engine 蓝图系统设计的轻量级字节数据转换插件。
支持原生类型和结构体与字节/Json 之间的双向转换，所有功能均以蓝图节点暴露。

🔧 插件初始化

Section titled “🔧 插件初始化”

插件启用后自动生效。
所有功能通过蓝图节点访问，无需管理子系统或插件生命周期。

🔣 支持的类型转换

Section titled “🔣 支持的类型转换”

📦 原生类型 ↔ 字节数组

Section titled “📦 原生类型 ↔ 字节数组”
类型转换支持
int32转为/转自字节
int64转为/转自字节
float转为/转自字节
double转为/转自字节
bool转为/转自字节
FString转为/转自字节（UTF-8 编码）

这些函数适用于自定义协议、轻量存储或二进制通信。

🧱 结构体 ↔ 字节数组 / Json 字符串

Section titled “🧱 结构体 ↔ 字节数组 / Json 字符串”

插件支持任何暴露给蓝图的 USTRUCT：

  • 与字节数组互转：Struct To Bytes / Bytes To Struct
  • 与 JSON 字符串互转：Struct To JsonString / JsonString To Struct

此功能使用 Unreal 的反射系统自动序列化和反序列化字段，同时保留原始命名和浮点精度。

⚠️ 不支持：包含对象引用的结构体，如 UObject*、TSoftObjectPtr、TWeakObjectPtr，或资源句柄如 FSoftObjectPath。

基础类型节点

Section titled “基础类型节点”

基础类型提供 ToBytes 和 FromBytes 双向转换：

类型转字节从字节还原
int32IntToBytesBytesToInt
int64Int64ToBytesBytesToInt64
floatFloatToBytesBytesToFloat
doubleDoubleToBytesBytesToDouble
boolBoolToBytesBytesToBool
FStringStringToBytesBytesToString

所有节点均为 BlueprintPure，可以直接在蓝图中作为纯函数使用，无需执行引脚。

结构体节点

Section titled “结构体节点”
  • StructToBytes / BytesToStruct：结构体与二进制字节数组之间转换。
  • StructToJsonString / JsonStringToStruct：结构体与 JSON 字符串之间转换。
