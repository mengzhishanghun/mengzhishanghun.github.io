SimpleAutoEnum/使用文档

从配置绑定枚举

支持的虚幻引擎版本：5.2–5.8

SimpleAutoEnum 是一个轻量级插件，可将 Unreal Engine 枚举自动绑定到可配置的字符串数组。 在项目设置中定义枚举值，插件会在运行时动态填充枚举条目。

⚠️ 注意：此插件需要 C++ 代码来定义枚举和配置数组，不是纯蓝图方案。

📝 使用方法

SIMPLE_BIND_ENUM_TO_CONFIG 宏参数：

  1. EnumType：你的枚举类（如 EMyWeapons）
  2. MinValue：起始边界值（如 None）
  3. MaxValue：结束边界值（如 Max）
  4. SettingsClass：继承自 UDeveloperSettings 的设置类
  5. ArrayProperty：设置类中 TArray<FString> 属性的名称

完整设置流程：

步骤 1：创建设置类

步骤 2：定义带边界的枚举

步骤 3：绑定枚举到配置

步骤 4：在项目设置中配置 前往 项目设置 > Game > Your Settings 并向数组中添加字符串值。

SimpleAutoEnum 使用指南

先定义枚举边界与 UDeveloperSettings 配置类，再通过绑定宏关联配置数组。原文的示例覆盖一对一绑定、多个范围绑定和多枚举共用数组。

绑定方式与数据处理

1. 一行宏完成绑定

原理:

  • 宏展开后创建静态初始化器,自动在引擎启动时注册
  • 无需在子系统中手动编写任何代码
  • 使用匿名命名空间避免符号冲突

2. 完善的数据验证

3. 灵活的边界定义
