创建 Curve 并替换通道

读取与写入

类型工具用途与主要参数
CurveGetCurve、CreateCurve、SetCurve读取或创建 Float、Vector、LinearColor 曲线；用 Channels 和对应完整旧通道 ExpectedValues 替换指定通道。未指定的通道保持原值。

创建或修改前先预览，确认后单独保存；见预览和保存规则。
