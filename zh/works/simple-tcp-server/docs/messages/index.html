节点函数说明
BindMessageHandle绑定消息接收委托
UnbindMessageHandle解绑指定委托
UnbindAllMessageHandle解绑所有委托

向单个会话发送或向通道广播

只回复一个客户端时，先按当前会话列表确认它的会话标识；确认要发给通道上的所有客户端时，再选广播。收发两端需使用同一种编码和分帧约定。

节点函数说明
SendMessage向指定 SessionChannel 发送字节数组
BroadcastMessage向通道上所有连接广播字节数组

客户端与字节转换

  • SimpleTCPClient 插件
    轻量客户端插件，可用于连接 SimpleTCPServer 实例。

  • SimpleByteConversion 插件 支持原生 Unreal 类型（如 FString、float、int）与 TArray<uint8> 之间的转换，适合构建结构化协议。
